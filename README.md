# Arcwhin Haul

Privacy policy for **Arcwhin Haul**, a browser extension for Google Chrome and
Microsoft Edge that lists the images and videos on a page and downloads the ones
you pick.

The policy is published at <https://acharwin.github.io/arcwhin-haul/>.

Short version: the extension collects nothing, stores nothing about you, and
sends nothing anywhere. This repository holds the policy page only — it is not
the extension source.
